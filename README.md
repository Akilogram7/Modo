# Modo

Modo is a personalized routine dashboard and automation hub. It is designed to simplify everyday activities through in-built modes and features. These modes are customizable, useful, and easy to activate everyday apps people use everyday. Instead of going through different applications to do their tasks, they can use modes through Modo that they set up themselves to best fit their needs. It combines multiple parts of their routine into one action and allows them to execute their routines with ease! 

Modo is not supposed to be a replacement for these features, just an easier way to go about using them. Having to spend less time on your device to get these features reduces risk of going off topic and being distracted from the task at hand. Encouraging efficiency, productivity, and accessibility!  

Modo has 3 preset features: Study, Commute, and Sleep while users can create their own custom modes as well 

Features: Alarm, blue light, Do Not Disturb, Location, maps and route calculation, transit timings, music, scratch pad, timer both regular and Pomodoro, and weather.

Accounts: Users can create their own account that saves all their preferences or they can use a guest account to test the basic features.

Tech Stack: 
Frontend - React Native, Expo, TypeScript
Backend - Supabase, PostgreSQL
Weather - Open-Meteo
Transit Data - DRT and GO Transit data
Maps - React Native Maps
Routing - OpenRouteService
Design - Figma 
Git, GitHub
